# 分级标准：Priority Score v0 与 S/A/B/C 阈值（数据驱动版）

> 本文档是 `configs/scoring_v0.yaml` 的论证记录。每一个阈值都来自对
> `02.插件数据源/` 与 `03.前端数据源/` 真实数据的分布分析，而不是拍脑袋。
> 权重框架继承《07_分层分析系统组任务书》§8；数值分档由本轮实采数据校准。

## 1. 校准数据集

| 数据源 | 范围 | 样本量 | 关键信号 |
|---|---|---:|---|
| Kalodata（插件） | TikTok Shop US 女装与女士内衣类目，2026-05-31~06-29 | 类目大盘 + Top10 商品 | 30 天销量/GMV（CNY 口径）、趋势数组、店铺集中度、深挖商品评分/评论/达人结构 |
| Tabcut（插件） | TikTok Shop US 全类目 Top 榜 + 视频原始行 | 24 商品 + 20 视频 | 销量、销量增长率、视频播放/互动/估算 GMV（USD） |
| EchoTik（插件） | 商品库页面可见表格 | 10 商品 | 7 天销量、7 天 GMV、评分、评论数、联盟达人数 |
| Shein（前端） | 女装连衣裙畅销序 200 款 | 200 | 销量下限、评分、评价数、售价/折扣、畅销榜、趋势标签、评价标签 |
| 独立站（前端） | freepeople / urbanoutfitters / anthropologie | 894 | 收藏数、售价、评分、评价数、设计细节 |

## 2. 市场需求（25 分）的分档依据

**量级（15 分，多信号取最强，防止同一需求重复计分）**

- TikTok 30 天销量：Kalodata 女装内衣 Top10 实测 2,536~86,499 件
  （p25/p50/p75 = 17.3k / 29.5k / 38.7k）；Tabcut 全类目 Top24 实测 56k~283k（p50=74k）。
  分档 `≥80k→15 / ≥30k→12 / ≥10k→9 / ≥1k→6 / >0→3`：80k ≈ 两个样本合并后的 p75，
  30k ≈ 女装类目 Top10 的中位数——即「达到类目头部中位水平」才拿 12 分。
- EchoTik 7 天销量：阈值 = 30 天档 ÷ 4（同一口径的时间换算，不是新标准）。
- Shein 销量下限（`100+`/`4.3k+` 只记下限）：实测 n=135，p50=100、p75=800、p90=1620、
  max=10000。分档 `≥2000→15 / ≥500→12 / ≥100→8 / >0→4`，2000 高于 p90——
  Shein 只有头部 10% 才能拿满。
- 独立站收藏数：**收藏是热度不是成交**，封顶 10/15。实测三站 p50≈200~526、
  p90≈856~7085、max=71534。分档 `≥5000→10 / ≥1000→8 / ≥300→5 / >0→2`。
- 评论数兜底（有人买才有评论，封顶 8/15）：`≥500→8 / ≥50→6 / ≥10→4 / >0→2`，
  对应 Shein p90≈62、独立站评论 p50≈3~5.5 的稀疏现实。

**动能（6 分）**：Tabcut 增长率实测 n=21，区间 [-20%, +186%]，p50=+38.9%，p75≈+80%；
Kalodata 趋势数组首尾增长 [-26.8%, +55.5%]。分档 `≥80%→6 / ≥30%→5 / ≥5%→3 /
≥-10%→2（平稳，常青特征）/ <-10%→0`。Shein 畅销榜标记（200 款中 76 款）记 4 分，
趋势标签（94 款）记 2 分——榜单是强动能证据，标签是弱证据。

**广度（4 分）**：需求证据覆盖的独立数据源数 `≥3→4 / 2→3 / 1→1`。
这是「多源互验」在分数上的体现。

## 3. 竞争可突破（20 分）的分档依据

- **类目集中度（6 分）**：Kalodata 实测女装内衣类目 Top3 店铺占比 4.23%、
  Top10 占比 11.86%、活跃店铺 19,111 家——极度分散，新卖家有进入空间。
  分档 `<20%→6 / <40%→4 / <60%→2 / ≥60%→0`，实测值落在最优档。
- **评论护城河（8 分）**：竞品评论门槛越低越好切入。TikTok 女装内衣头部（OEAK）
  实测 product_review_count=68,609（万级门槛）；Shein 连衣裙 p50=14、p90≈1000
  （含 `1k+` 解析值）。运行时取组内评论数 p90 作为竞争门槛代理并写入运行记录。
  分档 `<100→8 / <1000→6 / <10000→3 / ≥10000→1`。
- **价格带位置（6 分）**：候选价格落在 (source_group, currency) 组内
  [p25,p75]→6、[p10,p90]→4、之外→2。分位数运行时计算（样本 <20 不定位），
  **不做跨币种换算**——汇率不是采集事实。

## 4. 产品机会（20 分）的分档依据

- **痛点/改良空间（8 分）**：L1 用低成本代理——评分低于类目分布但有需求。
  Shein 评分实测 p25=4.29、p50=4.67：分档 `≤4.30（≈类目P25）→8 / ≤4.60（低于中位）→5 /
  >4.60→2（口碑好但改良空间小）`。
  L2 后改用真实负面评价标签聚类刷新：`≥3 个负面聚类→8 / 2→6 / 1→4 / 0→2`。
  负面词表 15 项全部来自 Shein 实采标签词汇（Never Received This Item×75、
  Runs Large×24、Wrong Size×16、See-Through×13 等），不自造标签，
  `No Smell` 等「No+负面词」为正面标签不误判。
- **差异化（7 分）**：有趋势标签/图案元素/设计细节记录→4；标题含 Patented/Exclusive
  等专利主张→3（BOOMBA "Patented Sticky Fashion Bra" 为实例）。
- **内容/渠道杠杆（5 分）**：OEAK 实测视频销售额占比 92.9%（¥871.99万/¥938.59万）、
  关联达人 594 个、Tabcut 视频最高播放 1.06 亿。分档 `视频占比≥50%→5 / ≥20%→3`；
  `达人≥500→4 / ≥100→2`；`播放≥1000万→3 / ≥100万→2`（取最强）。

## 5. 自有供应链（20 分）与风险（-15 分）

- **供应链**：P0 仓库中没有自有/供应链人工输入 → 整维记 `missing`，
  **不打 0 分、不用行业均值补**；achievable_max 从 85 降到 65，
  并写入 `required_next_data`。这就是缺失数据策略在评分上的执行。
- **风险规则**（命中即扣，落地 -15 下限，每条绑定证据或标「人工待确认」）：

| 规则 | 扣分 | 数据依据 |
|---|---:|---|
| 单一数据源 | -2 | 全部 Shein/独立站候选为单源；量价未经第二源互验 |
| 采集质量降级 | -3 | 独立站实测 63 行 ACCESS_CHALLENGE（未绕过，如实降级） |
| 只有热度证据 | -2 | 收藏/播放 ≠ 成交（总纲红线：趋势信号不能当销量） |
| 强季节窗口 | -3 | 万圣节（窗口 9-10 月）与图案连裤袜（秋冬）两组 1,076 款 |
| 品牌自营/IP | -4 | Kalodata seller_type=BRAND（OEAK 实测）；独立站全部为品牌自营 |
| 疑似品牌自营（启发式） | -2 | 店铺名品牌词出现在标题（medicube US Store × "[medicube]…"），只扣分不封顶 |
| 超低价 | -2 | 低于组内 p10（Shein p10=$5.49，$0.43 连衣裙为实例） |
| 低分高销 | -3 | 评分<3.5 且评论≥30 → 退货风险 |
| 达人集中 | -2 | OEAK 达人 GMV 集中度实测 40.3% |
| 新品从 0 起量 | -1 | Kalodata 趋势数组出现 +2.7 亿% 的退化增长率，标记不可解释 |

## 6. S/A/B/C 阈值校准

`pct = max(0, 总分) / achievable_max × 100`（P0 achievable_max=65）。
在全量 2,234 个真实候选上的 pct 分布：

| 分位 | p50 | p75 | p90 | p95 | p98 | p99.5 | max |
|---|---|---|---|---|---|---|---|
| pct | 20.0 | 27.7 | 36.9 | 41.5 | 46.2 | 50.8 | 60.0 |

**阈值：S=50，A=45，B=30**，加硬性条件：

- **S（≈前 0.5%）**：还必须 ①≥2 个独立数据源互验；②置信度 ≥ medium；
  ③无未确认的重大 IP/质量风险（命中 brand_ip 或 quality_degraded 封顶 A）。
  实测 7 款 S 全部为 Tabcut×EchoTik 双插件互验的头部商品（medicube 60.0%、
  ADDWIN 筋膜环 56.9% 等）。OEAK 文胸 52.3%（Kalodata×Tabcut 双源、high 置信度）
  因 seller_type=BRAND 侵权风险被规则封顶为 A——这正是硬性条件要防的场景。
- **A（≈前 2%）**：值得继续研究。头部 Shein 连衣裙（55.4%，畅销榜+销量 800+）、
  freepeople 高收藏款（52.3%）落在此档，单源候选最高只能到 A（single_demand_signal_cap）。
- **B（≈前 20%）**：暂存观察，低成本跟踪。
- **C（其余 ≈80%）**：暂不推进，只保留证据与淘汰理由。
  其中无任何需求信号的候选（图案连裤袜全部 534 款、万圣节大部分）由
  L1 Gate 直接降 C 并列入补采清单，与分数无关。
- **覆盖率封顶**：关键字段覆盖率 <35% 封顶 B、<20% 封顶 C——分数高但数据薄的候选
  不允许占据推荐位。

实测分布：S=7（0.3%）、A=48（2.1%）、B=387（17.3%）、C=1,792（80.2%）。

## 7. 三赛道标签规则

| 标签 | 规则 | 数据依据 |
|---|---|---|
| 趋势上升款 | 增长率 ≥30% 或带畅销榜标记 | Tabcut p50=+38.9% 之上为「明确上升」 |
| 基础常青款 | 增长率 [-10%, +30%) 且标题含基础款词（bra/tights/tank…） | 平稳带 + 常青品类词表 |
| 痛点改良款 | 评分 ≤4.30 且评论 ≥10 | Shein 评分 p25=4.29 |
| 价格带机会款 | 价格在组内 [p25,p75] 且类目 Top10 集中度 <20% | Kalodata 实测集中度 11.86% |
| 观察款 | 关键字段覆盖率 <35% 或无其他标签 | 兜底 |

## 8. 已知局限与调参入口

1. Kalodata 金额为 CNY 页面换算口径、Tabcut/EchoTik 为 USD——系统各报各币种，
   绝不使用固定汇率折算；跨平台价格带比较只做「分位位置」层面。
2. Tabcut Top 榜是全类目榜，女装候选在其中偏少；女装专属深度主要来自
   Kalodata（类目级）与 Shein/独立站（前端）。
3. 图案连裤袜 7 站没有任何需求/口碑字段——它们全部落 C 是**数据缺失的正确表达**，
   不是品类判断；补采（评论数、bestseller、库存变化）后会自动重排。
4. 供应链维接入人工输入后，achievable_max 恢复 85，S/A/B/C 阈值需按新分布重校准
   （重跑一次运行记录 sheet 即可拿到新分布）。
5. 所有阈值集中在 `configs/scoring_v0.yaml`，改配置即改标准，代码无需改动。
