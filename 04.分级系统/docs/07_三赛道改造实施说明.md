# 三赛道改造实施说明（tracks.v1，校准态）

> 依据：《开发部大项目7.13_选品项目全景理解与系统定位》《三赛道独立SAB分级_目标业务规则》
> 《选品分级系统P0改进交接与验收清单》（均在 `01.分级标准参考/`）。
> 范围排除（业务确认）：商品立项与产品定义、产品组合与上市回流不在本项目内。

## 1. 已实施（交接清单 §17「可立即实施范围」）

| 项 | 实现 |
|---|---|
| 三结果模型 | `track_eval.py`：每候选每 run 恰好 3 条 TrackEvaluation（唯一键 run_id+subject_type+subject_id+track_id），本轮实测 2,234×3=6,702 条 |
| 状态语义 | ELIGIBLE / PENDING_DATA / REJECTED；PENDING/REJECTED 的正式 grade 为空，仅导出兼容附 legacy_grade=C |
| 赛道键 | trend_new / hit_improvement / long_tail_direct + recommended_development_mode（开发方式与赛道分离，人审确认）；balanced 不再是业务赛道 |
| 趋势新品 | 准入=近期推出证据 AND 款型新颖度证据；**不设任何数据门槛**（销量/评论/GMV/收藏/增长率/畅销榜）；无销量绝不淘汰；多平台相似/内容只加权；单源早期可进 B |
| 爆款改款 | 三项联合准入（适量销量[组内相对分位草案]+低评分[相对/绝对+最小样本]+负面聚类≥2）；缺评论全文→PENDING_DATA；评分正常→REJECTED |
| 长尾直接选品 | 稳定需求（交易类证据，热度不计入；排除单次暴涨）+ 无阻断性质量问题 + 价格可判；不是关键词赛道、不是兜底赛道 |
| 新鲜度契约 | packet.freshness（listed_at/first_seen_at/new_arrival_flag/freshness_status/novelty_status/双证据链）；红线落地：观察≠上架、页面新≠款型新、Shein「新品集合位置」按规则 7.3.A 记为 inferred 证据 |
| 来源角色 | source_roles 多值（sources_p0.yaml 配置：独立站=discovery、Shein=transaction+voc+discovery、插件=transaction[+content]），独立站按发现源参与趋势判断，不再被结构性淘汰（本轮为 PENDING_DATA 待补而非 REJECTED/C） |
| 信号注册表 | track_eval.SIGNAL_REGISTRY 统一交易/热度/VOC 口径（评论数计入交易类）；旧 DEMAND_SIGNAL_FIELDS 标注 LEGACY |
| 机会簇骨架 | 风格词召回（召回≠确认）、cluster_id/version/成员关系证据/lineage、confidence=low 100% human_review=pending |
| 赛道独立预算 | 每赛道独立 l2/l3 队列（草案名额），互不挤占 |
| 交付表 | `三赛道选品推荐表.xlsx`：三张 SAB 表、跨赛道汇总、待补数据、未准入与淘汰依据、机会簇、数据源覆盖与角色、规则版本与运行记录（评分明细/证据索引/152键在主工作簿） |
| 存储 | selection.db 新增 track_evaluations 表；旧 results 表保留为 legacy 兼容 |
| 测试 | tests/test_track_eval.py 覆盖验收场景一/四/五/六/七/八、三条记录不变式、状态语义、确定性重算 |

## 2. 本轮真实数据回放结果（严格快照口径）

run_20260713_001（2,234 候选，不补字段）：

| 赛道 | ELIGIBLE | PENDING_DATA | REJECTED |
|---|---:|---:|---:|
| 趋势新品 | 0 | 2,234 | 0 |
| 爆款改款 | 0 | 2,140 | 94 |
| 长尾直接选品 | 655（草案分 S=29/A=624/B=2） | 1,422 | 157 |

解读：这正是规则文档要求的诚实结果——当前数据没有款型新颖度证据（历史款型库/
更早快照/业务确认均缺失），趋势赛道全部进入待补池并产出补采任务，而不是伪造
趋势等级；改款赛道被评论全文卡住；长尾赛道的草案分数明显未校准（A 偏多），
`rule_status=calibration` 如实标注。**受控增强回放**需在补采（上架时间、评论
全文、图片相似）后进行。7.11 的 2,000 款基线（06.分级系统数据源）不在本仓库，
回放对照需在其所在环境执行。

## 3. 待业务确认（阻塞正式生产等级，清单见 tracks_v1.yaml）

新款证据有效期、各来源新品标签可信度、适量销量分档、低评分边界与最小样本、
负面聚类口径、三赛道 S/A/B 阈值与 L2/L3 名额、款型历史库与回看窗口、
same_style/same_trend 阈值、确定性 REJECTED 红线。金标未确认前，
所有产出带 `rule_status=calibration_pending_business_approval`。
