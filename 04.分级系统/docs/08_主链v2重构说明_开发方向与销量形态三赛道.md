## 1. 新主链流程（tracks.v2）

```
公共事实层（采集/合并/证据/来源角色）
→ 公共 L0 技术检查（身份/标题/证据合法性；唯一公共 Gate）
→ 开发方向判定（进入系统第一步）
    铺货：无条件可选（不修改差评问题，仅微调外观结构）
    改款：评价数较多(≥50 草案) 且 差评比例超阈(0.15 草案；
          差评比例字段缺失时以评分≤4.2 代理，占位 confidence=low)
    改款方向 → 三赛道销量门限放宽 ×0.7（有差评的产品销量要求适当放低）
→ 三赛道扇出（销量表现形态；每候选每 run 恰好 3 条记录）
    新品 new_product：近期推出(近4个月草案) + 近期销量表现不错(组内分位≥0.40)
    爆款 hit：销量很高(组内分位≥0.75)；评分正常→铺货微调，低分+改款方向=爆款改款
    长尾 long_tail：销量表现稳定(交易证据+非单次暴涨)；低分仅阻断纯铺货方向
→ 各赛道内部 L1→L2→L3 分层淘汰（公共 L1/L2/L3 废止）
    等级上限随层放开：L1=B，L2=A，L3 才可 S（S 必须走完 L3）
    各赛道独立 l2/l3/补证预算，互不挤占
→ 各自 S/A/B → 跨赛道汇总（并列展示，人工决策开发方式）
```

**趋势独立体系（不在商品赛道内）**：对象=款式/设计特性词；来源=头部独立站
（discovery 角色）+ 社媒内容源；评分 ABCDE（站点广度 40 + 新品位占比 25 +
Amazon 语料稀有度 20 + 内容信号 15，草案）。产物：趋势词表ABCDE sheet +
trend_words.jsonl。小红书源结构性缺失已登记（接入按 docs/05 信封直投即可）；
当前 Amazon 语料为空时稀有度留槽 0 分标注「缺语料」。
