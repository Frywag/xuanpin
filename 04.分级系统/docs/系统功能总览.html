③ 输入从哪来

A. 仓库既有数据源（自动）

02.插件数据源/ 与 03.前端数据源/ 的 XLSX，注册在 configs/sources_p0.yaml，run 时自动读取。新增前端工作簿只加列映射配置。

B. 外部采集直投（推荐主路径）

按 docs/05 契约产出 source.envelope.v1 JSON：record = 标识 + fields 标准词表 + 逐字段 evidence。金额必须带币种；缺失不写不补 0。E级错误整封拒收。

C. 人工输入（终选款）

供应链能力档案 configs/supply_capability.yaml（一次性）；逐款成本/MOQ/交期仅对 L3 终选款（≤10）补录。

④ 标准怎么改

分级标准

configs/scoring_v0.yaml：赛道权重档、分档阈值、赛道内 S/A/B/C、风险规则。改配置即改标准，代码零改动；每个阈值带真实数据推导注释（docs/01）。

Gate 与成本

configs/layer_gates_v0.yaml：L2/L3/深度评审的对象与数量上限。

画像键注册表

configs/profile_keys_v1.yaml：152 键的直取路径 / 语义词表 / 人工键，来自业务三份模板。

⑤ 红线（引擎与校验器强制）

① 不编造任何数值——LLM 回灌经「证据白名单 + 数值封闭性 + 受控词表」机器校验，违规直接拒收；② 每条结论必须绑定 EvidenceRef（模型层强制）；③ 缺失=missing_fields，不补 0/均值；④ 价格必须带币种，跨币种不换算；⑤ 收藏/播放是热度不是销量；⑥ 等级与分数由确定性引擎计算，LLM 的改级建议需人审（human_review=approved）生效；⑦ 输出不含 token/cookie。
