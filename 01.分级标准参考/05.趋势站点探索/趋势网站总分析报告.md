# Pinterest Trends

## 新站初判

- 目标网站：https://trends.pinterest.com/
- 目标市场/币种：趋势情报站，无商品交易币种；当前可切换多地区，样本以 `美国` 为主
- 用户目标：判断该趋势网站哪些内容值得采集、对选品有没有价值，并明确其首页、二级页、三级页能抓哪些趋势字段回来做分析
- 最接近的历史案例：不属于零售站，更接近趋势/情报站
- 当前结论：适合采集

## 值得注意的内容

| 内容 | 为什么对选品/市场分析有价值 | 采集可行性 | 证据 |
|---|---|---|---|
| 焦点趋势 | 可快速发现近期爆发的主题词与所属垂类 | 高 | 首页可见 `Vacation Outfit Ideas`、`Room Decoration Ideas` 等及月增长 |
| 购物趋势 | 可直接判断哪些产品类别在增长，适合选品方向筛选 | 高 | `购物趋势` 页可见产品类别、增长率、出站点击次数 |
| 搜索趋势关键词榜 | 可抓取当下增长最快的关键词 | 高 | `搜索趋势` 页可见周/月/年变化、关键词榜单 |
| 单个关键词详情页 | 可抓趋势生命周期、相关热词、人口统计、热门 Pin 图 | 高 | `detail` 页可见时间序列、相关热门、年龄、性别、热门 Pin 图 |
| 编辑推荐 / Predicts | 可抓 Pinterest 官方策划的年度和主题趋势包 | 高 | 首页与 Predicts 页可见 `Gimme Gummy`、`Poetcore` 等趋势主题 |
| 地区维度 | 可做市场对比，判断同类趋势在不同国家的适配度 | 高 | 首页、购物页、详情页都带 `地区` 选择 |

## 页面与技术判断

- 商品发现入口：
  趋势站不以商品列表为核心，而是以 `趋势概览`、`购物趋势`、`搜索趋势`、关键词 `detail` 页、`Pinterest Predicts` 为主要入口
- 页面渲染方式：
  动态渲染，但页面恢复后可稳定读取可见文本与下钻链接
- 稳定数据源候选：
  浏览器 DOM、可见文本、关键词 detail 页、shopping/search 二级页、Predicts 专题页
- 需要点击/展开/滚动的区域：
  `查看购物趋势`、`查看搜索趋势`、`查看完整列表`、单个关键词详情页、Predicts 专题页
- 风险信号：
  首次导航命令可能超时，但恢复后页面可直接继续读取
- 不确定项：
  更深层关键词详情页是否还暴露更多可导出指标，后续仍可继续扩样

## 建议下一步

1. Smoke 采集范围：
   先固定美国市场，抓首页焦点趋势、购物趋势前 20、搜索增长趋势前 20、2-3 个关键词详情页
2. 需要人工确认：
   是否需要后续扩展到英国、加拿大、拉美等多市场对比
3. 预期产物：
   趋势关键词清单、产品类别清单、增长率字段、人口统计字段、相关热词字段、热门 Pin 图字段
4. 停止条件：
   页面连续两次无法恢复，或趋势明细页无法返回基础字段
