# 选品全流程工作安排 · 文件索引

本目录是“女装跨境选品全流程数据与分析系统”的执行文档包。文档面向两类读者：

1. 人类负责人：用于分配工作、检查进度、验收结果。
2. AI 大模型：用于直接接手具体任务并产出设计、代码、测试和交付文件。
