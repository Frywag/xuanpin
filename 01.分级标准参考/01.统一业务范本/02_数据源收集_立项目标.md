# 立项：选品数据源收集与封装

> 版本 V0.1 草案（待你和团队评审）  日期 2026-06-24
> 上游对接：本项目产出喂给「产品开发（选品/改款/新品）→ Priority Score → Canonical 152键 → 铺货底座」。
> 背景锁定：主类目 = 女装；目标平台 = Amazon / TikTok Shop / Shein（D4）。

---

## 1. 立项目标（一句话）

**盘清、采集、封装"女装跨境选品/产品开发"所需的全部可获取数据源，固化成可被选品 skill 直接消费的结构化数据与 MCP，并明确拿不到的缺口。**

成功标准：能用真实数据跑通一条端到端样例——`一个关键词/品类 → 市场+竞品+差评+趋势数据 → 喂进 Priority Score → 产出 S/A/B/C 候选 + 152键事实`。

---

## 2. 为什么要立这个项目（和下游的关系）

产品开发三种模式各自依赖不同数据，能不能跑通，取决于数据拿不拿得到：

| 模式 | 成立的前提数据 | 拿不到会怎样 |
|---|---|---|
| 选品 | 市场销量 + 竞争结构 + 价格带 + listing事实 | 无法判断市场够不够大、挤不挤 |
| 改款 | **差评全文** + 竞品listing + 退货原因 | 找不到改良点，改款无从下手 |
| 新品 | **趋势数据**（搜索/社媒上升元素）+ 竞品参考 | 抓不到风向，新品=拍脑袋 |

→ 所以"收集数据源"不是杂活，它直接决定三条产品线哪条能成立。

---

## 3. 数据源全景（团队按域分工去收）

### 域① 第三方调研工具（量化市场面）

| 平台 | 可能的工具 | 能拿到的关键字段 | 喂给下游 |
|---|---|---|---|
| Amazon | 卖家精灵 / Helium10 / JungleScout | 关键词搜索量·ABA、市场月销量/销售额、竞争集中度、价格带、新品上榜能力、流量结构、Review数趋势 | Priority Score：市场维度 + 竞争维度 |
| TikTok Shop | EchoTik / FastMoss / Kalodata / TikTok创意中心 | 热销榜、达人带货量、视频挂车转化、标签热度 | 趋势赛道 + 竞争维度 |
| Shein | （成熟工具少）第三方榜单 + 自采 | 品类榜、热销/新品、加心数(收藏热度)、上新节奏 | 爆款/趋势赛道 |
| 趋势风向 | Google Trends、小红书/抖音热词、Pinterest Trends | 关键词/风格/配色的上升趋势 | 趋势赛道权重输入 |

> 关键判断：Amazon 工具最成熟，Shein/TK 数据弱 → 后两者更要靠**前台爬取 + 社媒情报**补。

### 域② 平台前台爬取（定性产品面 + 152键事实源）

| 平台 | 爬取对象 | 重点字段 | 喂给下游 |
|---|---|---|---|
| Amazon | BSR榜/New Releases/Movers&Shakers、listing详情 | 标题五点、主图副图、变体、评分、**差评全文**、Q&A、上架时间、价/Coupon/Deal | 152键事实 + 改良清单 + 上架窗口判断 |
| TikTok Shop | 热销榜、商品详情、带货视频 | 商品属性、评论、视频元素 | 152键 + 趋势元素 |
| Shein | 品类/热销/新品榜、商品详情 | 款式属性、评分评论、收藏热度、价格、上新频率 | 152键 + 爆款信号 |

> 女装重点：**差评聚类 → 改良清单**（版型/面料/做工/尺码痛点）是"改款"模式的命脉，必须能批量拿到差评全文。

### 域③ 社媒/趋势情报（女装尤其重要）

小红书穿搭笔记热度与爆文元素、抖音/TikTok 穿搭达人与标签/BGM 趋势、Pinterest/Instagram 风格与配色走向、快时尚标杆（Zara/H&M/Shein）上新节奏。→ 主要喂**趋势赛道**和**新品开发**的灵感与方向。

### 域④ 自有数据 & 供应链

现有款库（SPU/SKU）、历史动销、**退货率与退货原因**（女装关键）、毛利、库存；供应商名录、打样成本、起订量 MOQ、生产周期、面料库。→ 喂 Priority Score 的**自有维度**（供应链匹配/毛利红线/起订门槛），是"机器初筛能不能直接砍候选"的硬指标。

### 域⑤ 合规/侵权数据

商标库（USPTO/EUIPO/中国商标网）、外观专利、平台违禁与品牌白名单/VeRO。→ 支撑立项前的 R3 四项侵权自查（本体/商标/外观专利/平台AI政策）。

---

## 4. 交付物

1. **数据源清单**：每个源的可得性、字段、粒度、时效、成本、限制、覆盖平台。
2. **每源采集方案**：API / 爬虫 / RPA / 手动导出，含频率与反爬对策。
3. **封装产物**：卖家精灵等封装成 MCP；前台爬取做成可复用采集脚本；输出统一结构化。
4. **缺口清单**：想要但拿不到的数据，及其对三种模式的影响。
5. **端到端样例**：跑通一条"关键词→各源数据→Priority Score 输入"的真实链路。

---

## 5. 任务分工（按数据源域）

| 组 | 负责域 | 产出 |
|---|---|---|
| 工具组 | 域① 第三方工具 | 各平台工具账号/配额盘点 + 卖家精灵 MCP 封装 |
| 爬取组 | 域② 前台爬取 | 三平台采集脚本 + 差评全文批量获取 |
| 趋势组 | 域③ 社媒情报 | 趋势热词/元素的采集方案 |
| 供应链组 | 域④ 自有&供应链 | 现有数据导出 + 成本/MOQ/退货原因结构化 |
| 合规组 | 域⑤ 侵权 | 商标/专利/平台政策查询通道 |

> Claude 的角色：每个源接进来后逐个调用核对真实返回，标注字段用途，最终出选品/市调 skill 草案。

## 6. 优先级与排期建议

- **P0（先做，数据最成熟、对应样板 D4）**：卖家精灵 + Amazon 前台爬取（含差评）。
- **P1**：TikTok / Shein 前台 + 社媒趋势 + 自有/供应链。
- **P2**：合规侵权查询通道 + 趋势工具深度接入。

| 风险 | 对策 |

### A2. 平台前台爬取 —— 按平台与页面

**Amazon**
- 榜单：Best Sellers、New Releases、Movers & Shakers（按女装细分类目）→ 爆款/新品信号。
- Listing 详情页：标题、五点、A+、主图/副图、变体(颜色尺码)、价格/Coupon/Deal、BSR、评分、评论总数、上架日期、品牌、卖家 → **152键事实 + 上架窗口**。
- 评论区：**差评全文(1-3星)**、带图评论、Q&A → 差评聚类改良清单。

**TikTok Shop**
- 商城热销榜/飙升榜、商品详情、挂车视频与达人、评论 → 趋势元素 + 152键。

**Shein**
- 品类榜/Trends/New In/热销、商品详情(款式属性/面料/价格)、评分评论、**收藏("加心")数**、上新节奏 → 爆款信号(收藏热度是 Shein 特色) + 152键。

### A3. 社交媒体 / 趋势情报（女装命脉）
- **小红书**：穿搭笔记/爆文元素、热门话题、博主带货款 → 趋势赛道 + 新品灵感(中国审美)。
- **抖音**：穿搭达人、热门 BGM/话题、同款链接 → 趋势元素。
- **TikTok(内容侧)**：穿搭 hashtag 热度、达人、挑战 → 趋势(欧美审美)。
- **Pinterest**：风格/配色/版型走向、Pinterest Predicts 年度预测 → 新品方向。
- **Instagram**：博主/品牌风格、Reels 趋势 → 风格参考。
- **快时尚标杆监测**：Zara / H&M / Shein 上新节奏与爆款，作"风向标"对照。

### A4. 自有 & 供应链
- 现有款库(SPU/SKU)、历史动销、**退货率与退货原因**(版型/尺码/面料/做工/色差——女装退货主因) → 自有维度 + 改款方向。
- 供应商名录、打样成本、起订量 MOQ、生产周期、面料库与克重/弹性参数 → 自有维度硬门槛 + 152键面料类字段。
- 自有店铺运营数据：自家 listing 表现、广告 ACoS、客服高频问题 → 验证 + 改良。

### A5. 合规 / 侵权查询
- 商标：USPTO(美)、EUIPO(欧)、中国商标网。
- 外观专利：各局专利检索、平台 VeRO 品牌名单。
- 平台政策：各平台违禁词/品牌白名单/AI 图政策。
- → 支撑立项前 R3 四项侵权自查（本体 / 文字商标 / 外观专利 / 平台 AI 政策）。
