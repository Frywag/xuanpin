## §1 选品 Priority Score 引擎（domain=priority_score；驱动商品 S/A/B/C）

**统一公式（三赛道共用，赛道只调权重，A10）**

```
Priority Score = 趋势分×25% + 爆款验证分×20% + 长尾机会分×15%
               + 利润分×15% + 供应链可做分×15% − 风险分×10%
```

| 子分 | 数据源（情报源，非销售平台 A8） | 口径 |
|---|---|---|
| 趋势分 | Google Trends/Pinterest/TikTok CC/Lyst/品牌站 | 搜索上升斜率、社媒声量增速、上新 |
| 爆款验证分 | Amazon BSR/Temu/AliExpress/SHEIN 榜与评论 | 销量、评论数、复购、评分 |
| 长尾机会分 | 站内搜索词/细分类目/Etsy | 长尾搜索量、低竞争度、利基匹配 |
| 利润分 | 中台成本/利润 | 边际贡献预估 |
| 供应链可做分 | 供应数据 | 可采、可扩、交期 |
| 风险分（减） | 风险信号 | 侵权/退货/尺码/季节窗口 |

**权重档（可配置，weight_profile）**：默认档如上；趋势店调高趋势分；清货店调高利润+供应链分。**【TODO赋值】各档具体权重**。

**分箱→商品等级（A1/A9）**

| 分箱 | 等级 | 默认动作 |
|---|---|---|
| 高 | S 超级潜力 | 优先开发、多平台复用铺货 |
| 中高 | A 主力 | 正常铺货 |
| 中 | B 测款 | 小批量测款 |
| 低 | C 清仓/不做 | 不进或清退 |

## §2 风险分级发布引擎（domain=publish_risk）★ M4 核心

**发布风险等级 = f(操作性质, 内容质量分级, 店铺成熟度)**，输出「自动 / 人工」。与刊登级别 L1–L4 正交（A3）。

```
IF 操作=确定性(价格/库存/上下架/字段直填)        → 自动（走规则引擎+映射引擎，硬隔离LLM, A4/R5）
IF 内容质量=P0(虚构/禁用词/侵权/合规违禁)          → 禁止发布（硬卡，回修）
IF 内容质量=P1(堆词/夸张/偏离定位)                → 人工评审后发
IF 内容质量=P2(可读性/卖点不足)                   → 可自动发布 + 记建议
IF 创造性内容(图文) AND 店铺成熟度<门槛           → 人工评审 + 灰度（R4）
ELSE                                            → 自动 + 成熟度门槛 + 可回滚
```

## §5 双利润与复制/退出门（domain=replicate_exit）L1

**双利润口径**

- **边际贡献利润** = 扣直接变动成本 → 判单个 SKU 是否继续测试。
- **全成本利润** = 扣应分摊固定成本 → 判市场/平台/店铺/品类是否继续投入。
- **成本血缘六层**：战略进入 / 平台店铺 / 品牌知识产权 / 产品准入认证 / 商品经营 / 售后风险。

**决策门（命中即触发，阈值【TODO赋值】）**

| 门 | 触发条件（要点） |
|---|---|
| SKU 加码 | 连续周期边际贡献为正 + 扣广告退货仓储资金占用后仍正 + 周转健康 + 差评退货投诉低于红线 + 供应稳定 + 合规齐全 |
| 品类复制 | 一组 SKU 盈利(非单个) + 供应可扩 + 内容/广告/客服可复用 + 合规可复用 + 有价格带人群 |
| 平台复制 | 原平台已验证真实利润 + 目标平台需求价格带匹配 + 成本结构清楚 + 素材客服供应链可迁移 |
| 国家复制 | 原市场稳定真实利润 + 前置成本可测算 + 税务VAT/EPR/认证/清关/退货链路清楚 + 一组SKU可摊国家级固定成本 |
| 停止复制 | 销售涨但全成本利润持续为负 / 周转恶化 / 仓储退货广告吞利润 / 合规无法摊薄 / 账号风险上升 / 增量只转移销量 / AI workflow 无法稳定处理异常 |

承载：`t_rule(domain=replicate_exit)` + `t_project` + `t_cost_item/t_profit`。

## §6 内容质量分级（domain=content_quality）→ 喂 §2 发布风险

| 级别 | 判据 | 处置 |
|---|---|---|
| **P0 禁止发布** | 虚构事实、命中禁用词、合规违禁、侵权 | 硬卡，回修 |
| **P1 需人工审核** | 关键词堆砌、夸大宣传、偏离店铺定位 | 强制人工评审后发 |
| **P2 建议优化** | 可读性、卖点不突出 | 可自动发布，记建议 |

**禁用词库命中 → 直接 P0**。侵权判据四项（R3）：产品本体 + 文字商标 + 外观专利 + 平台 AI 政策。承载：`t_rule(domain=content_quality)` + 禁用词库表。
